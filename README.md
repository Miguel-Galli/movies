
# 📽️ Movies App

Um aplicativo Flutter simples que exibe uma lista de filmes. Este projeto é multiplataforma e funciona em Android, iOS, Web, macOS, Windows e Linux.

### 🚀 Funcionalidades

- Visualização de uma lista de filmes.
- Tratamento de erros de carregamento de dados.
- Interface responsiva.

### 🛠️ Estrutura do Projeto

- `lib/main.dart`: ponto de entrada do app.
- `lib/movies_list.dart`: widget principal que mostra a lista de filmes.
- `lib/movies_list_error.dart`: tratamento de erros na exibição da lista.

### 📦 Dependências

As dependências estão especificadas no `pubspec.yaml`. Para instalar, execute:

```bash
flutter pub get
```

### ▶️ Como Rodar

1. Clone o repositório.
2. Execute `flutter pub get`.
3. Rode o app com:

```bash
flutter run
```
